FREQUENTLY ASKED QUESTIONS

Can I test multiplayer on a single laptop?

Yes! Open one regular browser window (e.g. Chrome) and an Incognito/Private window. Sign in as two different users (or use the instant Guest mode) and join the same room code.

How does server validation prevent cheating?

The browser never receives the correct answer ahead of time. When you select an answer, the server checks correctness against its secure database, computes speed from the server's master clock, and calculates scores server-side.

Are the sound effects copyright-free?

100%! All game sound effects are generated algorithmically in real time using the browser's Web Audio API oscillators. No external audio files are required, ensuring zero missing asset errors.
