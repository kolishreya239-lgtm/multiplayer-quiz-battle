RULES & SCORING SYSTEM

A completely transparent, server-validated scoring model rewarding both accuracy and lightning speed.

Point Allocation Breakdown

Outcome Base Score Speed Bonus Streak Bonus Max Potential
Correct Answer 100 PTS 0 to 50 PTS 0 to 100 PTS 250 PTS
Incorrect Answer 0 PTS 0 PTS 0 PTS (Streak Reset) 0 PTS
Unanswered / Time-Out 0 PTS 0 PTS 0 PTS (Streak Reset) 0 PTS

Speed Bonus Algorithm

The faster you correctly answer, the higher your speed multiplier:

Speed Bonus = round( ( (Question Time - Response Time) / Question Time ) * 50 )

Example: In a 15-second round, submitting a correct answer in 1.5 seconds earns 100 base + 45 speed bonus = 145 points!

Consecutive Streak Bonus

Consecutive correct answers build streak momentum. Starting from the 2nd consecutive correct answer, an escalating bonus is added:

Streak 1
+0 PTS
Streak 2
+20 PTS
Streak 3
+40 PTS
Streak 4
+60 PTS
Streak 5+ (Max)
+100 PTS

Fair Play & Anti-Tampering Architecture

  • Zero Client-Side Answers: The correct answer and explanation are retained strictly on the Python backend until all players answer or the clock expires. Inspecting browser DevTools or WebSocket payloads will not reveal the answer.
  • Lockout Protection: Each player is permitted exactly one submission per question. Duplicate or subsequent submissions are blocked on the server.
  • Server Master Clock: Question durations and timestamps are determined by Python high-precision server timers, preventing local clock manipulation.
